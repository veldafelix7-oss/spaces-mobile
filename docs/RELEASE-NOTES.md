# spaces : mobile — initial native preview
Landscape Android game space for Tecno Spark 20C / Android 13.

- Opt-in installed-game collection (PUBGM FLASH and Blood Strike only).
- Lightweight glass-style native UI, Indonesian / English.
- User-started foreground sessions, pull-out movable overlay, local temperature/RAM/battery monitoring.
- Optional Shizuku GameManager and display-refresh preferences with a durable recovery journal.
- Focus mode, local session history and battery-temperature charts.
- No ads, accounts, trackers, recording, WhatsApp shortcuts or game-file modification.

**Limitations:** not an OEM system Game Space. No FPS-unlock, verified FPS capture, render downscale, automatic process stopping, global EQ or touch-driver control. Device validation is required. Profile settings may not change performance. Recovery after process death/reboot requires reopening the app and, if needed, reconnecting Shizuku.

Install updates over the existing app. Preview and release have separate application IDs/signing identities. Read README and docs/TESTING.md before testing.
